📈 Stock Portfolio Tracker

A simple and efficient Python-based Stock Portfolio Tracker that allows users to manage their stock investments, calculate total value, and export results to a CSV file.

🚀 Features
📊 Track multiple stocks with quantities
💰 Automatic calculation of individual and total investment value
🧾 Export portfolio data to a CSV file
🛑 Input validation for better user experience
⚡ Lightweight and beginner-friendly Python project
🛠️ Technologies Used
🐍 Python 3
📂 CSV Module (built-in Python library)
📦 How It Works
The program displays a list of available stocks.
User enters stock symbols and quantities.
The program calculates:
Individual stock value
Total portfolio value
Data is saved into a file named portfolio.csv.
