# 📈 Stock Portfolio Tracker

A simple and efficient **Python-based Stock Portfolio Tracker** that helps users manage stock investments, calculate total value, and export results to a CSV file

## 🚀 Features

• Track multiple stocks with quantities
• Automatic calculation of individual and total investment value
• Export portfolio data to a CSV file
• Input validation for better user experience
• Lightweight and beginner-friendly


## 🛠️ Technologies Used

• Python 3
• CSV Module (built-in)


## 📦 How It Works

• Displays available stocks
• User enters stock symbols and quantities
• Calculates individual and total investment value
• Saves data into `portfolio.csv`


## 📋 Available Stocks

• AAPL (Apple)
• TSLA (Tesla)
• GOOGL (Google)
• MSFT (Microsoft)
• AMZN (Amazon)

## 📄 Example Output

Portfolio Summary
AAPL — Qty: 2, Price: $180, Value: $360
TSLA — Qty: 1, Price: $250, Value: $250

Total Investment Value: $610


## 📁 Output File (portfolio.csv)

• Stores stock, quantity, price, and value
• Includes total investment value
