# 🌐 Web Page Title Scraper

A lightweight and beginner-friendly **Python Web Scraping Tool** that fetches a webpage and extracts its **title**, then saves it to a file.

---

## 🚀 Features

• Fetches webpage content using HTTP requests
• Extracts the `<title>` tag using regular expressions
• Saves the extracted title to a text file
• Simple and easy-to-understand code
• Perfect for beginners learning web scraping

---

## 🛠️ Technologies Used

• Python 3
• Requests Library
• Regular Expressions (re module)

---

## 📦 How It Works

• User enters a webpage URL
• Program sends a request to the URL
• Extracts the page title from HTML
• Saves the title into `title.txt`
• Displays the result on the screen

---

## 📄 Example Output

```id="6btv27"
Enter the URL of the webpage: https://example.com
Page title: Example Domain
Saved to title.txt
```

---

## 📁 Output File

• `title.txt` → Contains the extracted webpage title

---

## ⚠️ Notes

• Works only if the webpage is accessible (status code 200)
• Requires internet connection
• Some modern websites may block scraping requests
