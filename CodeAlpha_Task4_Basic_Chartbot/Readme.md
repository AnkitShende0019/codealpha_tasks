# 🤖 Simple Rule-Based Chatbot

A beginner-friendly **Python Chatbot** that interacts with users using predefined rules and responses. This project demonstrates basic **natural language handling** and conditional logic.

---

## 🚀 Features

• Responds to basic greetings like "hello" and "hi"
• Handles simple conversations like "how are you"
• Exits the chat on "bye" or "exit"
• Case-insensitive input handling
• Lightweight and easy to understand

---

## 🛠️ Technologies Used

• Python 3
• Basic Conditional Logic
• String Processing

---

## 📦 How It Works

• User enters a message
• Input is converted to lowercase for consistency
• Program checks keywords using conditions
• Returns a predefined response
• Continues conversation until user exits

---

## 💬 Supported Commands

• "hello" / "hi" → Greeting response
• "how are you" → Status response
• "bye" / "exit" → Ends the chat
• Any other input → Default response ("Tell me more.")
